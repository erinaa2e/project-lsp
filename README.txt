OCEANGO — WEBSITE BOOKING KAPAL

FITUR
- Beranda modern
- Pencarian tiket
- Hasil jadwal kapal
- Detail kapal & fasilitas
- Login & register
- Pilih kursi interaktif
- Data penumpang
- Pembayaran demo
- E-ticket / cetak tiket
- Responsive desktop & mobile
- MySQL untuk akun pengguna (opsional; website tetap bisa demo tanpa MySQL)

CARA MENJALANKAN DI XAMPP
1. Extract folder oceango_booking ke:
   C:\xampp\htdocs\oceango_booking

2. Jalankan Apache di XAMPP.
3. Jika ingin memakai database:
   - Jalankan MySQL.
   - Buka phpMyAdmin.
   - Import file database.sql.
   - Pastikan database bernama "oceango".
   - Konfigurasi default: user root, password kosong.
4. Buka:
   http://localhost/oceango_booking/

ALUR DEMO
Beranda → Cari Tiket → Pilih → Detail → Pilih Kursi → Data Penumpang → Pembayaran → E-Ticket.

CATATAN
- Pembayaran adalah simulasi untuk tugas/prototype.
- Jika MySQL belum aktif, register/login tetap dapat dicoba menggunakan penyimpanan sesi demo.
